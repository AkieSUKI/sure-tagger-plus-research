# 标签版本对比：2026-10-09 公共 schema → 研究侧 v0.6

核对日期：2026-10-27。对照的是用户指定的共享 schema，不是仅比较研究侧 v0.5→v0.6。

比较指定的 2026-10-09 公共 schema 与研究侧 v0.6：旧版 32 个结构父字段、2 个派生字段、12 个描述父字段以及额外 gender 评分轴，与 51 种 t_* 音频语义的计数粒度不同。新表示补充时间、声学细节与关系候选，并把既有信息分入观察、派生、元数据和描述层；未删除旧公共字段，也不代表51类均已实现。

## 1. 比较范围与计数

| 项目 | 计数与含义 |
| --- | --- |
| 旧六个结构分组 | 32 个父字段：basic 5、quality 5、room 3、sound 4、speaker 10、language 5 |
| 旧 deterministic_derived | 2 个字段；与上项合计 34 |
| 旧 descriptive | 12 个父字段；其对象孩子随父字段覆盖 |
| 旧 gender | 额外评分轴 speaker.gender，实际 JSON 在 descriptive.speaker_descriptions[].gender；不是第 33 个结构父字段 |
| 新 t_* | 51 种音频语义：L1 8、L2 5、L3 3、L4 13、L5 18、L6 4 |
| 能力边界 | 总表 51/51 表示名称覆盖；6 类明确 ∅，其他类型也含条件、部分支持和待核权重 |

同一旧父字段可以对应多个新观察，一个新观察也可支撑多个旧字段。下文是多对多语义映射，不能将 51−32 解释成“新增19个标签”，也不能将关系类型数当作独立声音信息维数。`added` 表示旧公共字段没有显式表达的声音语义或分辨率，不表示旧管线内部完全没有相关输出。

真正扩充的内容主要是词/音素和事件时间、局部语言切换/不流畅、声纹匹配、声质与情绪、频谱/音符/声像、多通道关系及音频交互候选。人数、重叠、切换、语速、词数、RT60 的语义旧版已有，本次主要细化时间、保存原始观察或增加另一种感知路径；其中直接声学词数和 RT60 尚无确认 producer。

所谓“省略”是退出独立感知节点：文件属性移到 L0，重复的统计/补集/分档/拼接移到 d_*，自然语言继续在描述层；旧公共接口与原值不因本次展示而被删除或改写。

- **六类 ∅**：`t_voicing`、`t_spectral_envelope`、`t_phonation`、`t_spatial_image`、`t_word_count`、`t_rt60`。前四类完整输出未确认，后两类只保留直接感知候选。

- **旧文档本身允许独立预测粗粒度字段**：音乐存在性、说话人存在性、文字统计与派生比率等在跨系统评测可有独立预测。此处把 sure-tagger 的确定性路径记成 d_*，不授权覆盖其他系统原预测。
- **文档核对不等于模型实验**：本次完成语义、引用和计数校验；没有新增模型推理或准确率验证，不宣称最小完备集或可还原唯一波形。
