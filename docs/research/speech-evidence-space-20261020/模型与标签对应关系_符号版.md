# 模型与标签对应关系：符号版

版本：`speech-evidence-space-20261020.v0.6`。本文件以 [Tag Schema](../../../../../../../mnt/cloudstorfs/sjtu_home/huifei.wang/sure-tagger-plus-research/docs/research/speech-evidence-space-20261020/tag_schema.md) 与 [模型对应总表](../../../../../../../mnt/cloudstorfs/sjtu_home/huifei.wang/sure-tagger-plus-research/docs/research/speech-evidence-space-20261020/模型与标签对应总表.md) 为现行依据，只展开声音标签、确定性派生路径和模型中间证据。模型来源、版本与接口细节保留在文末链接的调查中。

## 1. 符号与状态

```text
x                   同一段输入音频；额外文字、目标声源等条件在箭头上标明
{m1,m2}             共同参与的模型/工具；{m1 / m2} 表示替代 producer
{m} -> {t_*}        音频属性观察及必要归属关系
{已有观察} -> {d_*}  固定规则重算；引用父证据，不增加独立类型
{m} -> {e_*}        接口实际暴露的模型分数、向量或中间波形
[D]                 文档或已实现接口直接返回
[C]                 条件组合、适配或确定性后处理
[H]                 任务头、权重、接口、标注或校准尚待核实
∅                   尚无确认 producer，不是可调用模型
```

`t[k]` 只限定粒度、类别、声源或表示方式，不另建类型。相同属性的直接观察与派生路径可以并存；模型数、观察数、标签类型数与独立信息维数分别计算。下文列全现行 **51 类 `t_*`、15 条 `d_*`**；状态不代表已经本地运行或验证准确率。

## 2. 音频属性的模型路径

### 2.1 文字、语言与对齐

```text
{m_qwen_asr} -> {t_text,t_language}                                      [D]
{m_qwen_aligner} --[given={x,t_text,t_language}]--> {t_word_time}         [C]
{m_qwen_asr,m_qwen_aligner} -> {t_text,t_language,t_word_time}            [C]
{m_qwen_asr,m_qwen_aligner,m_diarizer}
  -> {t_text,t_language,t_word_time,t_spk_activity,t_unit_speaker}        [C]
{m_moss} -> {t_text[segment/speaker],t_unit_speaker,t_spk_activity}       [D/C]
{m_firered_aed_asr} -> {t_text,t_word_time}                              [D/C]
{m_firered_lid} -> {t_language}                                        [D]
{m_firered_aed_asr,m_firered_lid,m_firered_vad}
  -> {t_speech_activity,t_language,t_text,t_word_time}                   [C]
{m_firered_llm_asr} -> {t_text}                                        [D]
{m_whisper_base} -> {t_text,t_language,t_word_time}                      [D/C]
{m_sensevoice} -> {t_text,t_language,t_word_time,t_emotion,t_event}       [D/C]
{m_dicow / m_se_dicow} -> {t_text,t_word_time,t_unit_speaker}            [C/H]
{m_mfa} --[given={x,t_text,词典,语言声学模型}]--> {t_word_time,t_phone_time} [C/H]
{m_paraformer / m_paraformer_stream / m_fun_asr_nano / m_fun_asr_mlt / m_glm_asr_nano}
  -> {t_text}                                                          [D]
```

逐说话人 ASR 是 `t_text[speaker]`，已有文字的拼接另用 `d_speaker_text`。MFA 的规范/词典音素对齐不等于实际音值识别；其具体输出粒度仍待确认。不同 ASR 的时间戳有各自对齐条件，失败插值不当作对齐成功。

### 2.2 说话人、活动与时间结构

```text
{m_nemotron / m_sortformer} -> {t_spk_activity}                          [D/C]
{m_diarizen / m_pyannote} -> {t_spk_activity}                            [D/C]
{m_speechbrain_ecapa,m_spectral_clustering}
  --[独立音频分段、声纹、非oracle自动聚类；适配簇数]--> {t_speaker_count} [C]
{m_pyannote_osd_legacy} -> {t_overlap_interval}                          [C/H]
{m_pyannote_scd_legacy} -> {t_speaker_change}                            [C/H]
{m_sylnet} --[音频音节计数 / 窗口秒数]--> {t_speech_rate_value[syllable/s]} [C]
{m_cam_zh / m_cam_en / m_ecapa / m_wespeaker} -> {t_same_speaker_candidate} [C]
{m_alice} -> {t_gender}                                                [D/C]
{m_cam_en,m_afri_head} -> {t_gender}                                    [D/C]
{m_ecapa,m_griko_svm} -> {t_gender}                                     [D/C]
```

OSD/SCD 的专用任务与解码源码已核实，具体权重及现代环境兼容未核实；OSD 不自动给参与者，SCD 不自动给切换双方或互动意图。CountNet 的窗口最大同时人数不等于整段不同说话人总数，不能替代 `t_speaker_count`。SylNet 音节率不是词率，也不是去停顿发音速度；与 ASR 词率不能直接数值互证。

### 2.3 声学量、事件与音乐

```text
{m_firered_vad / m_firered_stream_vad / m_silero / m_fsmn_vad}
  -> {t_speech_activity}                                                [D/C]
{m_brouhaha} -> {t_speech_activity,t_snr,t_c50[Brouhaha]}                 [D/C]
{m_firered_event_aed} -> {t_event_interval}                              [D/C]
{m_dass / m_panns_cnn14 / m_panns_wavegram / m_beats_classifier}
  -> {t_event}                                                         [D/C]
{m_panns_sed} -> {t_event,t_event_interval}                              [D/C]
{m_dnsmos_835,m_dnsmos_808} -> {t_mos_sig,t_mos_bak,t_mos_ovrl,t_mos_p808} [D/C]
{m_rec_rir} -> {t_rir}                                                 [D]
{m_opensmile,m_profile} -> {t_jitter,t_shimmer,t_hnr}                     [C/H]
{m_opensmile} --[导出平滑LLD；尚待适配]--> {t_f0[frame],t_loudness[frame]} [C/H]
{m_profile} -> {t_f0[median],t_rms[summary]}                             [C]
{m_torchcrepe} -> {t_f0[frame]}                                         [D/C]
{m_basic_pitch} -> {t_note_event[pitch/onset/model_offset/pitch_bend]}   [D/C，部分支持]
{m_emotion_plus / m_emotion_finetuned} -> {t_emotion}                    [D/C]
{m_emotion_plus,m_opensmile,m_emotion_base}
  -> {t_arousal,t_valence,t_stress,t_engagement}                         [C/H]
```

profile 当前只返回干净语音的 F0/RMS 摘要。openSMILE 的 functionals 不能冒充 LLD 轨迹；内部 F0 门控和 torchcrepe periodicity 也不自动成为校准后的独立有声状态观察。Basic Pitch 有复调音高与模型起止，但未确认混音逐乐器/声部归属或符合 schema 的可听 offset，CSV velocity 不等同感知 loudness。

### 2.4 条件组合与尚缺 producer 的类型

```text
{m_wesep,m_asr} -> {t_text[target],t_word_time[target]}                  [D/C/H]
{m_asr} -> {t_self_repair_candidate,t_hesitation_span}                   [C/H]
{m_event,m_diarizer} -> {t_event_source_candidate[human]}               [C/H]
{m_nemotron,m_sortformer,m_pyannote,m_qwen_asr,m_qwen_aligner}
  -> {t_interruption_candidate,t_backchannel_interval,t_repair_sequence} [C/H]
{m_asr,m_qwen_aligner,m_firered_lid} -> {t_code_switch_span}             [C/H]
{m_wesep,m_asr,m_brouhaha,m_dnsmos_835,m_diarizer}
  -> {t_speech_activity[target],t_snr[target],t_mos_ovrl[target]}         [C/H]
{m_panns_cnn14,m_beats_encoder,m_clap_audio} -> {t_event_interval}        [C/H]
{m_brouhaha,m_dnsmos_835}
  --[given=同源多通道波形；时间与质量规则]-->
  {t_channel_sync_offset,t_channel_consistency,
   t_channel_dropout_candidate,t_channel_quality_skew}                  [C/H]
{m_redimnet_oasr / m_legacy_aligner_oasr / m_legacy_diarizen_oasr / m_legacy_firered_aed_oasr}
  -> {t_word_time,t_spk_activity,t_event}                               [候选/不可调用]
∅ -> {t_voicing,t_spectral_envelope,t_phonation,t_spatial_image}         [H]
∅ -> {t_word_count,t_rt60}                                             [H]
```

这些组合沿用总表的候选范围，不表示每个模型都有原生任务头。事件归属的已有人声组合不自动支持非人声持续性；区间相交不能证明归属、打断或附和。重复/填充语可以复用 `t_event` 类别研究，但 SEP-28k 是标注数据，不是已确认模型；clip 标签不能冒充次数或精确犹豫 span。词数仅有直接声学回归项目 README 声明，RT60 的 BERP 输出链未核实；两者均无确认 producer。

## 3. 已有观察的15条派生路径

```text
{t_text} --[冻结tokenizer、重复/filler规则]--> {d_text_statistics}
{t_spk_activity} --[统计不同ID及存在性]--> {d_speaker_summary}
{t_text,t_unit_speaker} --[按已接受归属排序拼接]--> {d_speaker_text}
{t_spk_activity} --[同坐标活动并集]--> {d_speech_activity}
{t_spk_activity} --[全局/指定pair交集及统一分母]--> {d_overlap}
{t_spk_activity} --[continuity/gap/边界规则]--> {d_turn_structure}
{已有回应对应关系及其时间点} --[时间差]--> {d_response_latency}
{t_text,t_word_time,语音掩码} --[明确单位与分母]--> {d_speech_rate}
{t_f0,t_rms,t_loudness} --[归属筛选、裁剪、平滑、归一化]--> {d_contours}
{t_f0,t_rms,clean_mask} --[固定片内参照与阈值]--> {d_profile_bands}
{t_speech_activity或d_speech_activity} --[有效范围内补集及占比]--> {d_nonspeech}
{t_rir} --[固定RT60/C50算法；metric_source=RIR]--> {d_room_metrics}
{t_event,t_event_interval,e_event_frame_scores}
  --[类别过滤、并集时长比；帧比另需原帧分数及hop]--> {d_event_summary}
{e_event_scores及对应t_event} --[排除表、映射、top-k、音乐门控]--> {d_background_categories}
{t_event_interval及已接受的发言时间轴} --[相交、先后、邻接]--> {d_event_timing}
```

规则路径使用所需父观察的子集；缺失不能填零或伪装为空集合。新模型的重叠、人数、切换、语速等观察与上述计算分别保存；比较前对齐语义、时间范围、分母与类别集。事件区间占比不能反推原始帧占比，类别过滤也不证明声音处于背景；同一语音二分类的负类不算第二个独立模型。

## 4. 模型中间证据

| 证据 | producer / 暴露条件 |
| --- | --- |
| `e_spk_frame_scores` | Nemotron、Sortformer 等实际返回的逐帧说话人分数 |
| `e_spk_embedding` | CAM++、ECAPA、WeSpeaker 等实际暴露的声纹向量 |
| `e_speech_frame_scores` | FireRed VAD、Silero、FSMN-VAD 等的原始帧分数 |
| `e_event_scores`、`e_event_frame_scores` | DASS/PANNs/BEATs 类别分数；帧分数仅限实际支持的 SED 接口 |
| `e_token_score`、`e_token_posterior` | ASR 接口确实暴露时保留，不由最终文字补造 |
| `e_audio_embedding`、`e_text_embedding` | CLAP、BEATs、PANNs 等各自支持的编码器；文本向量仅限相应文本编码器 |
| `e_acoustic_tokens` | BEATs 等实际暴露的声学 tokenizer 输出 |
| `e_acoustic_feature_bundle` | openSMILE eGeMAPSv02 原始特征包；名称、单位、配置与聚合方式随分量保存 |
| `e_target_waveform` | WeSep 所选提取模型的目标波形；依具体 checkpoint 与条件 |
| `e_latent_embedding` | 模型实际暴露的 hidden state；未暴露接口保持待核，不能一概断言 `[D]` |

分数、embedding 与中间波形不是新的声音标签。向量需保留 checkpoint、空间、层和时间粒度，不同模型的裸向量不可直接混合比较。模型帧分数经定义明确的解码可产生活动/事件观察，但同一分数的不同阈值不能计作独立感知。
